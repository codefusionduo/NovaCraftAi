# **App Name**: NovaCraft AI

## Core Features:

- Text-to-3D Model Generation: Generate 3D models from a text prompt, using the format: Object + Style + Material/Texture + Pose/Orientation + Optional Reference. Generates 4 draft models for selection. Uses a tool that analyzes user inputs and chooses when to add supporting detail to prompts to refine the final results.
- 3D Model Gallery: Display generated 3D model drafts in a gallery format for user selection.
- Text-to-Texture Generation: Generate textures for a selected 3D model based on a user-provided text prompt.
- Texture Application: Allow users to select a 3D model draft and apply AI-generated textures to it.
- Model Download: Enable users to download the generated 3D model with applied textures in a common 3D file format (.glb).

## Style Guidelines:

- Primary color: Saturated purple (#A663CC) to evoke creativity and futuristic vibes.
- Background color: Dark gray (#2A2A2D) to provide contrast and focus on the 3D models.
- Accent color: Electric blue (#7DF9FF) for interactive elements and highlights.
- Body and headline font: 'Space Grotesk' (sans-serif) for a techy, scientific feel.
- Use clean, minimalist icons to represent different functionalities and settings.
- Arrange the UI to clearly showcase the 3D model drafts and provide easy access to texturing and download options.
- Subtle transitions and animations to provide feedback during the 3D model and texture generation processes.
